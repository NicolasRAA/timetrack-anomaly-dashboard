# Обнаружение аномалий в телеком-сети с помощью автоэнкодера

Интерактивный дашборд на базе Streamlit для детекции аномалий в вычислительном кластере OpenAirInterface (CI/CD).  
Используется неконтролируемое обучение (автоэнкодер) для выявления нештатных ситуаций по ошибке реконструкции.

## Назначение
Помочь оператору связи быстро находить отклонения в работе серверов без ручного анализа десятков графиков.  
Автоэнкодер обучен на «нормальных» паттернах нагрузки и сигнализирует, когда совместное поведение метрик (CPU, память, диск) становится нетипичным.

## Данные
Датасет **TimeTrack** (собран с кластера OAI CI/CD, предоставлен Eurecom, доступен на Kaggle: `abdelghanimeliani/open-air-interface-cicd-timeseries-dataset`).  
В проекте используется файл **`compute_dataset.csv`** (41 362 записи, 45 признаков) — метрики памяти (AM/UM), CPU (CU/CF) и дисковой подсистемы (DRT/DWT) для 7 виртуальных машин.  
Период: 24.06.2024 – 19.07.2024.

## Метод
- **Модель:** Автоэнкодер (Keras/TensorFlow): вход 45 → Dense(32) → Dropout(0.1) → Dense(16) → Dropout(0.1) → Dense(16) (bottleneck) → Dense(16) → Dense(32) → Dense(45, linear).
- **Обучение:** 100 эпох, batch=256, оптимизатор Adam, функция потерь MSE, early stopping (patience=10).
- **Обнаружение аномалий:** Для каждой временной точки вычисляется ошибка реконструкции. Точки, превышающие **95-й перцентиль** ошибки, считаются аномальными.
- **Ключевой инцидент:** 18.07.2024 15:18:55–15:19:37 (42 секунды). Зафиксирован всплеск CPU и дисковой активности, который без автоэнкодера мог остаться незамеченным.

## Запуск локально
Для клонирования репозитория и запуска на своём компьютере (нужен Python 3.10+):

```bash
git clone https://github.com/ваш-логин/timetrack-anomaly-dashboard.git
cd timetrack-anomaly-dashboard
python -m venv venv
# Активация venv:
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
Откройте у себя браузер по адресу `http://localhost:8501`.

## Деплой на Streamlit Community Cloud
1. Загрузите репозиторий на GitHub (публичный).
2. Перейдите на [share.streamlit.io](https://share.streamlit.io) и авторизуйтесь через GitHub.
3. Нажмите «New app» и укажите репозиторий, ветку (main) и главный файл `app.py`.
4. Убедитесь, что в репозитории есть файл `runtime.txt` с одной строкой `3.11` (это важно для совместимости TensorFlow с Python в облаке).
5. Через минуту приложение будет доступно по публичной ссылке.

## Структура репозитория
```
├── app.py                  # основной код Streamlit-дашборда
├── requirements.txt        # зависимости Python
├── runtime.txt             # версия Python для Streamlit Cloud (3.11)
├── packages.txt            # системные пакеты (опционально)
├── compute_dataset.csv     # данные (автоматически скачиваются при локальном запуске, в облаке должен присутствовать)
├── .streamlit/
│   └── config.toml         # тема и настройки Streamlit
├── .gitignore
└── README.md
```

## Пример использования
1. После запуска дашборд обучает модель (1–3 минуты) и кэширует её.
2. На главной странице отображается график ошибки реконструкции с порогом аномалии.
3. Слайдер «Чувствительность» позволяет менять процентиль порога (90–99).
4. Выпадающий список «Машина» переключает детализированные метрики для конкретного узла.
5. Ниже — сводка по ключевому инциденту и расшифровка значимости на понятном языке.
